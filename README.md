# Grey Modern Monochrome CV Website

## Project Overview

This project is a responsive CV/Resume website developed as part of a Front-End Development course. The goal was to create a modern curriculum vitae layout inspired by a monochrome design while applying fundamental web development concepts.

The website is built using HTML and CSS, with a strong focus on clean structure, responsive design, and visual consistency. Styling is separated into an external CSS file to follow best practices and improve maintainability.

## Features

* Responsive layout for desktop and mobile devices
* Modern monochrome design
* Two-column CV structure
* Professional profile section
* Experience, education, skills, and portfolio sections
* External CSS stylesheet for organized styling
* Semantic HTML elements

## Technologies Used

* HTML5
* CSS3
* Google Fonts

## Learning Objectives

This project demonstrates:

* Semantic HTML structure
* CSS layout techniques using Grid and Flexbox
* Responsive web design principles
* Separation of content and presentation
* Clean and maintainable front-end code organization

## Course

Created as part of a Front-End Development course project.
